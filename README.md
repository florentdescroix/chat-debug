# Sytême de messagerie instantanée avec salons

## Description
Cette applicaiton propose un système simple de messagerie instantané permettant à des utilisateur·ice·s identifié·e·s de communiquer dans différents salons.

## Installation
Utiliser la commande `npm install` pour installer les packets nécessaires au lancement du serveur.

## Mise en service
Server (prod) : lancer le serveur avec le commande `npm run serve` 
Server (dev) : lancer le serveur avec le commande `npm run dev` 

## Info
La partie client de l'application est disponible dans le dossier `public`
